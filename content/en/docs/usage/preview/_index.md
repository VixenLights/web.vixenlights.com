Building your display in the Preview mostly means drawing [Basic Shapes]({{< ref preview-basic-shapes >}} "Basic Shapes") and [Smart Objects]({{< ref smart-objects >}} "Smart Objects") — but if you have a prop that doesn't fit either one, model it in the [Custom Prop Editor]({{< ref custom-prop-editor >}} "Custom Prop Editor") instead, which you can launch right from the Preview toolbar.
